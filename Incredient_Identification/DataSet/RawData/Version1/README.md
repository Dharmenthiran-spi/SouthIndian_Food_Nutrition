# 📥 Raw Data Sources - Ingredient Identification (Version 1)

This directory documents the raw, uncurated culinary and recipe repositories evaluated and utilized for **Model 2: Food Image to Ingredient Prediction**.

---

## 📚 Repositories Evaluated

| Dataset Name | Domain / Cuisine | License | Suitability for Model 2 | Status |
|---|---|---|---|---|
| **Archana's Kitchen Indian Food Recipes** | Authentic South & Pan-Indian | **CC BY-SA 4.0** | **High**: Exact ground-truth photo-to-recipe pairings | **Primary Source** |
| **RecipeDB (IIIT Delhi CosyLab)** | Indian Computational Gastronomy | Open Research | **High**: Canonical Indian ingredient ontology | Reference Ontology |
| **Khana Dataset** | Pan-Indian Dishes | CC BY 4.0 | Medium: Bounding boxes without ingredient lists | Cross-referenced |
| **CMIngre** | Chinese Food | Academic | None: Incompatible cuisine & ingredients | Excluded |
| **FoodSeg103** | Western Cuisine | Academic | None: Western ingredients only | Excluded |
